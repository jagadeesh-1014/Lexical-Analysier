## 🧩 Lexical Analyzer Project

### 📌 Overview

This project implements a **lexical analyzer** for a C-like language. The lexer reads source code character by character and converts it into meaningful tokens such as keywords, identifiers, constants, operators, special characters, and preprocessor directives.

### ✨ Features

* 🔍 Tokenization of C-like source code
* 🏷️ Support for keywords, identifiers, constants, operators, and delimiters
* ⚙️ Preprocessor directive handling (`#include`)
* ⏭️ Whitespace skipping and error detection
* 🧱 Modular design using header and source files

### 📁 Project Structure

* `lexer.h` – Token definitions and function declarations
* `lexer.c` – Core lexical analysis logic
* `main.c` – Driver program to test the lexer

### 🔄 How It Works

The lexer uses a **state-based approach** to read characters from a file, build lexemes, classify them using predefined rules, and returns one token at a time until the end of file is reached.

### 🌍 Applications

* 🏗️ Compiler front-end development
* 🔌 Embedded command and protocol parsing
* 🎓 Educational tool for understanding compiler design

### 🛠️ Technologies Used

* C programming
* File handling
* Structures and enums
* Character classification (`ctype.h`)
